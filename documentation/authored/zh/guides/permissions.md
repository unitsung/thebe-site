# 配置权限

Thebe Core 把“能访问什么”和“这次是否执行”分开处理。部署时先把两种边界一起设好。

## 工作区

`THEBE_WORKSPACE_DIR` 是 Agent 可以自由读写的根目录。Core 不会把启动目录自动当成工作区。不要把它指向宿主机根目录、整个主目录或包含无关凭据的目录。

## Token

每个客户端使用独立 token，丢失时只撤销那一台设备。token 具备完整 API 权限，没有内建作用域；拿到 token 的人可以读取审计、修改设置和执行允许的工具。

## 审批

默认权限模式是 `manual`。自由文本不是执行授权，有风险的动作应该显示为具体变更并要求确认。

`bypassPermissions` 会移除命令守卫、沙箱和审批，只适用于你明确控制的短期会话。

## MCP 写操作

经 `/mcp` 接入的 Agent 自己负责向用户确认。Core 不在这条路径上弹出内部审批。需要只读时设置：

```bash
THEBE_MCP_WRITES=off
```

无论开关如何，每次写操作都会进入审计记录。
